✦ Overview
NovaCalc is more than a traditional calculator.

It is a complete calculation workspace designed to provide users with quick access to mathematical, scientific, conversion, financial, and utility tools through a single responsive interface.

The project was built with Next.js and React, with a strong focus on usability, responsive design, reusable components, and smooth interactions.
